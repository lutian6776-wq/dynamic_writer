# 墨迹 · 个人真实手写模拟与模板填充系统（一期）

将中文文本（含英文、数字、标点）渲染为**本人真实手写笔迹**，精准填入实验报告、课堂记录等 PDF/图片模板并支持整体或套打高清 PDF 输出。

## 核心功能

1. **EMR 平板采集闭环**
   - 生成带四角同心定位标、页眉 16-bit 编号条码、淡青色辅助格的 A4 矢量采集表 PDF（支持内置高频字库及按当前文档缺字生成增量采集表）。
   - 局域网二维码扫码打开 `/mobile` 平板页面，直接下载采集表 PDF 在安卓平板笔记 App 中手写并回传，自动对齐、去格切字入库。
2. **个人多变体字库与二期 AI 少样本补字**
   - 支持同字录入多份真实变体并防相邻重复轮换；同一字符只要后续录入平板真迹，自动优先覆盖 AI 补全版本。
   - **本地 GPU 少样本推理（FontDiffuser）**：支持利用你已采集的 1~4 个代表性真迹字直接在本地 NVIDIA GPU（4GB GTX 1650 实测稳跑）推理补全未录入的缺字，并在编辑器中以淡紫下划线标注（打印时无任何标注）。
3. **拟真排版与人为瑕疵引擎**
   - 视觉字距、标点紧贴、中文避头尾换行、平滑弹性形变、基线柔和漂移、墨色与笔锋粗细调节（匹配手补公式真笔）。
   - 支持内联 `[错字->正字]` 错字划掉重写、低概率随机错字、书写疲劳渐变。
4. **可视化模板填框与双模式导出**
   - 上传 PDF/图片模板，支持单行填空、多行横线（自动探测横线行距、首行避让印刷标题、跨页串联续写）及表格批量粘贴（支持自动识别表格行列）。
   - 一期缺字支持预览标红提醒及导出精准留白（打印后用真笔补写）；支持 **300/600 DPI 含底图整体打印** 与 **纯手写层套打（含毫米级 XY 校准页）**。

## 快速启动

```powershell
# 1. 安装依赖（首次）
python -m pip install -r backend\requirements.txt
cd frontend; npm install; cd ..

# 2. 一键启动前后端
.\start.ps1
```
